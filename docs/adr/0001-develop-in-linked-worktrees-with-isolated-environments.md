# Develop in Linked Worktrees With Isolated Environments

Every change is developed in a linked git worktree, and `pnpm setup:worktree` gives each one its own Convex cloud dev deployment (`dev/worktree-<id>`, expiring after five days), its own unclaimed WorkOS environment, and its own dev-server port. Parallel agents therefore never share a database, an auth tenant, or a port, and each can sign in, seed data, and verify end to end without coordinating with the others. The main checkout only anchors the Convex project: `pnpm bootstrap:main` creates the project and gives its dev deployment placeholder WorkOS variables so codegen and pushes work, and setup refuses to run there so it cannot clobber the anchor. Nothing remote is destroyed on teardown; Convex expiry and abandoned unclaimed WorkOS environments are the cleanup, which trades some remote litter for teardown that can never delete the wrong thing.
